First-Contact Language Access Tool — QI prototype

Upload index.html and the audio/ and cards/ folders to the root of your GitHub Pages repository. Preserve file names and folder structure. In Settings > Pages choose Deploy from a branch, main, /(root).

This is a prototype, not a clinical interpretation tool. Verify recordings and card translations with qualified speakers before real-world use. Kurdish dialect is not yet verified. The client-held card is a crop of the right side of the supplied image.

Read aloud uses browser speech synthesis and depends on browser/device support. Reviewed-language state is in memory only and clears on refresh.
